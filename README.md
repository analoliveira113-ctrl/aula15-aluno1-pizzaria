🍕 Pizzaria Bella Napoli — App & Web App de Notificações Locais

Bem-vindo ao repositório oficial da Pizzaria Bella Napoli! Este projeto foi desenvolvido para a disciplina de Programação para Dispositivos Móveis II (Aula 15) com o objetivo de demonstrar a integração de notificações locais no sistema operacional Android utilizando React, Capacitor e Tailwind CSS.

🎯 Sobre o Projeto

O aplicativo simula a experiência de pedido de uma pizzaria artesanal italiana, permitindo que o cliente acompanhe o status do seu pedido através de notificações nativas do smartphone — funcionando perfeitamente em primeiro plano, segundo plano ou com o app fechado.
